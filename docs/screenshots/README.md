# Capturas pendientes

No se incluyen imágenes inventadas ni capturas de una versión distinta. El lanzamiento automatizado de Chrome fue rechazado por la política de procesos del entorno.

Con Chrome instalado y el servidor en ejecución, `npm run test:browser` genera las capturas de menú, juego, recuperación, resultados y vista móvil. Revísalas visualmente antes de incorporarlas al README o al video.
