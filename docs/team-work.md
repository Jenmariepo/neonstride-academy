# Organización del trabajo académico

La distribución siguiente es una propuesta de responsabilidades. Cada integrante debe realizar cambios propios, documentarlos mediante commits y poder explicar el funcionamiento completo del proyecto.

| Integrante       | Área propuesta                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------- |
| Diego Heredia    | Motor, tablero, cronómetro, dificultad, entidades, controles y pruebas de las mecánicas. |
| Jenmarie Polanco | API, validación, base de datos, repositorios, clasificación y pruebas de persistencia.   |
| Ambos            | Revisión del código, pruebas en dispositivos, documentación, video y defensa individual. |

El historial inicial identifica la base preparada con asistencia de IA. La distribución no acredita autoría de cambios que todavía no se hayan realizado. Las aportaciones individuales deben describir modificaciones reales y su verificación.

La entrega requiere un video de cinco a ocho minutos con participación de ambos integrantes. Los guiones y las notas de ensayo se conservan como material personal fuera del repositorio. El documento técnico, la auditoría y las instrucciones de ejecución permanecen en la documentación pública.
